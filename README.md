### 📌 Project Overview

Analyzed unemployment trends in India before and during Covid-19 using Python. Visualized the massive impact of lockdown on job markets across states using real government data.

This project was completed as **Task 2** for the **CodeAlpha Data Analytics Internship**.

---

### 🔍 Key Insights from Analysis

1. **Lockdown Peak:** Unemployment rate crossed 25%+ during April-May 2020 lockdown
2. **Covid Impact:** Average unemployment jumped 60% - from 9.40% in 2019 to 15.10% in 2020  
3. **Worst Hit States:** Tripura, Haryana, and Jharkhand recorded highest average unemployment rates

---

### 📈 Visualizations Created
